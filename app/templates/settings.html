How keys are found

Ansible finds a key by the path in your inventory's ansible_ssh_private_key_file. Each key you add here is saved under its name and linked at:

    {% for p in key_paths %}
  • {{ p }}
    • {% endfor %}

So the name must match the file name in the inventory path. For /home/ansible/.ssh/ansible-ed25519, add a key named ansible-ed25519.

Keys must be unencrypted, since runs are unattended. The Commands page uses the same keys (a host's ssh_key is a key name).
